## 〇、全局来源规范（所有科目统一）

### 0.1 「使用模拟题」的正确姿势

机构模拟题（王道/肖四肖八/腿姐/启航等）与真题一样受版权保护，**逐题原样录入与录入真题的版权风险相同**。因此分两种模式：

| 模式 | 做法 | 适用 |
|---|---|---|
| A. 自用录入 | 你已购得纸质/电子材料，逐题录入本地库（个人学习用途，合理使用范围） | 仓库保持私有 |
| B. 风格自编 | 以这些材料的**考点分布、难度梯度、干扰项设计风格**为参照，原创编写同风格题目 | 仓库 MIT 开源发布 |

本方案默认按 **B 模式**组织（与现有 quiz-ds 200 题的做法一致——那批题即「王道风格自编」）。若你选 A 模式，结构完全不变，只是内容来源换成录入，但建议将 `data/` 下题库文件加入 `.gitignore`。

## 二、数学一

### 特殊性
考研数学题形为 8 选择 + 6 填空 + 9 解答，与 408 纯选择不同。quiz 引擎目前只有四选一，填空/解答不适合线上即时判分。

### 安排（分两类组织）

1. **选择题 → quiz**：每章 15~20 题进章末 quiz（现有引擎直接支持），覆盖概念辨析、反例判断、快速计算类
2. **解答/证明题 → 「练习块」**：新增轻量块用法（不改编译器）：用 keypoint 块组织——points 放题面与提示，details 放「分步解答」（`{h:'第一步：…', body:'…'}` 逐层展开），效果即「先做后对答案」
3. 填空题归入选择题类（本质是低提示度的计算题）或练习块，按章节实际内容定

来源参照：李林 880（基础巩固）/ 108（强化）的题型配比。

## 四、英语一（修订：阅读全部模拟）

### 4.1 结构
沿用五件套（原文分块 / 词汇 table / 长难句 error 块 / 5 题 quiz / 逐题解析），每篇 = 1 chapter。作文模板板块不变。

### 4.2 模拟题质量控制标准（回应「贴近考试实际」）

不用真题后，模拟题质量是最大风险。立以下硬标准，不达标的篇目不录入：

1. **命题点类型覆盖**：每篇 5 题须覆盖至少 3 种题型（主旨 / 细节 / 推理 / 词义猜测 / 态度题），比例参照真题（细节与推理为主）
2. **干扰项设计**：错误项须有明确错因类型（偷换概念 / 以偏概全 / 无中生有 / 张冠李戴 / 程度失当），逐题在解析中标明错因分类——这既是录入标准也是解析内容
3. **难度校准**：文章长度 400±50 词，长难句每篇 ≥3 处，生词率控制在真题水平（超纲词有注释）
4. **批次规划**：第一批 20 篇（模拟阅读），验证五件套结构与做题体验后，再决定是否扩量

### 4.3 词汇卡与作文
- vocab.js 熟词僻义 quiz：第一批 200 词内
- writing.js 小作文六类 + 大作文三段式框架与范文（与原计划一致）
