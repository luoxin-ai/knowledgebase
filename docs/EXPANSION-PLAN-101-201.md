## 二、政治部分

### 2.1 知识梳理（四个模块文件）

每模块对齐考研政治大纲章节，沿用精讲+详解结构：

| 模块 | 预估规模 | 块类型侧重 |
|---|---|---|
| 马原 | ~8 章 / 60 块 | concept 辨析（唯物vs唯心等）+ keypoint 原理方法论 + table 对比 + formula 不用 |
| 毛中特 | ~10 章 / 70 块 | keypoint 为主（纯记忆型），table 做「会议/文件/第一次」时间线 |
| 史纲 | ~8 章 / 55 块 | table 时间线 + keypoint 大事件意义 + error 易混淆点 |
| 思修法基 | ~6 章 / 40 块 | keypoint + table（法律条文类） |

- 每个知识点块带 `exam: { freq, forms, score }`（沿用刚上线的考试权重标注）
- [[口诀]] 标记大量使用（政治背诵特性）
- 每模块配 quiz 文件（单选+多选），复用 `hidden:true + quizFor` 机制

### 2.2 引擎扩展（政治必需）：多选题支持

现状：quiz 引擎只有四选一。政治 17 题 × 2 分多选是拉分主战场。

改动（`renderer.js` renderQuiz + initQuiz，约 50 行）：

```js
// 数据格式扩展：
{ stem: '……', multi: true, options: [...], answer: 'abd', explain: '……' }
```

- `multi: true` 时选项点击为「勾选/取消」状态，底部出现「提交」按钮
- 判定：全对得分；多选/少选/错选均不得分（政治规则，可在 explain 中说明）
- 计分条区分单选/多选统计
- 现有单选题零影响（无 multi 字段走原逻辑）

### 2.3 时政处理方案（三个问题逐一回应）

**① 是否设独立时政板块：设，且必须是独立 file（shizheng.js），不并入任何模块。**

理由：
- 时政是全书唯一「有效期一年」的内容，独立文件便于考前整体替换而不动四个模块
- 大纲时政范围是「1 月~12 月国内外重大事件」，与四个模块的知识结构无交集
- 现有架构下 file 级独立 = 侧边栏独立入口 + 搜索独立分组，天然满足

**② 如何归类热点：按专题为 chapter，按月份为 block 的二级结构。**

```
shizheng.js
├── chapter: 重大会议与讲话（最高频）
│   ├── block: 全国两会要点（3 月）
│   ├── block: 中央全会/经济工作会议（按实际召开）
│   └── block: 重要讲话与新增表述
├── chapter: 国内重大成就
│   ├── block: 科技成果（按月聚合）
│   └── block: 重大工程与政策
├── chapter: 国际时政与中国外交
│   ├── block: 大国关系与峰会
│   └── block: 全球治理与中国方案
└── chapter: 纪念活动与周年考点（4/9/5/10 等整数周年必考）
```

理由：时政选择题的考法是「专题内辨析」（如多个会议的提法区分、多个成果的时间排序），按专题组织与考法对齐；月份只作为 block 的属性信息放在标题或 summary 里，避免纯按月组织导致同一专题被时间切碎。

**③ 考前如何更新汇总：三步走。**

1. **平时（现在~10 月）**：框架先建、内容选填。shizheng.js 按上述 chapter 结构搭好，已发生的重大事件（如上半年两会、重要会议）先录入，每月补一次
2. **考前（11 月）**：对照各机构押题卷（肖四肖八等公开资料的知识点，非题目本身）交叉验证，补齐遗漏专题——这个动作我在你确认后可以协助做
3. **临考（12 月）**：时政 file 整体重写为「考前冲刺版」，只保留 30~50 个最可能考的 block + 一份多选 quiz，旧版归档

补充建议：时政块加 `exam: { freq: '高频' }` 统一标注 + summary 里写「XX 月」时间属性，方便快速扫读。

## 三、英语一部分

### 3.1 阅读理解（reading/）

**结构**：每篇阅读 = 1 个 chapter，含原文分块 + 题目 quiz + 解析块：

```
chapter: 2011 Text 1
├── block: 原文（concept 块，按段落分 details，长难句在段内标注）
├── block: 词汇注释（table：生词/熟词僻义/固定搭配）
├── block: 长难句分析（error 块复用：wrong=直译歧义，right=正确拆解，why=结构分析）
├── quiz: 5 道题（四选一，复用现有引擎）
└── block: 逐题解析（table 或 keypoint：正确项依据定位 + 错误项错因分类）
```

- 真题优先：先做 2010-2020 共 44 篇（每年 4 篇），模拟题视质量再定
- 每篇预计 3-4 个 block + 5 题，单文件（每年）约 16-20 个 chapter
- 文件按年代切分（reading-2011.js 等），避免单文件过大

### 3.2 作文模板（writing.js）

```
writing.js
├── chapter: 小作文（应用文）
│   ├── block: 建议信 / 感谢信 / 邀请信 / 道歉信 / 通知 / 备忘录（各 1 block：格式模板+参考范文）
│   └── block: 小作文通用句式与框架
├── chapter: 大作文（图画作文）
│   ├── block: 万能框架（三段式：描述图画→阐释寓意→评论建议）
│   ├── block: 话题分类模板（个人品质/社会热点/文化交流/教育……各 1 block）
│   ├── block: 高分替换与句式升级表（table）
│   └── block: 参考范文 3-5 篇
└── chapter: 作文避坑（error 块：常见语法错误/模板痕迹过重问题）
```

### 3.3 选配：词汇卡（vocab.js）

熟词僻义 + 形近词辨析做成 quiz（选择题型），规模视需求定，第一批 200 词以内。

## 四、合理性/可行性意见（你要求我给的判断）

### 方案合理的部分

1. **政治部分完全可行且性价比高**。政治与 408 考查形态同构（辨析+刷题），现有架构零浪费；多选题引擎改动小（~50 行）
2. **时政独立板块的判断是对的**。有效期一年的内容必须与长期知识隔离，file 级独立是正确粒度
3. **英语真题阅读结构设计合理**。原文+词汇+长难句+quiz+解析的五件套就是精读的标准动作，error 块复用做长难句拆解是巧思

### 需要调整/补充的地方（我的具体意见）

1. **⚠️ 英语真题的版权红线**：考研英语真题原文版权在教育部考试中心。个人本地使用没问题，但这个仓库是 MIT 开源的（README 写明），**如果打算公开仓库，真题原文不能进 git**。建议：阅读文件加入 `.gitignore` 或改为「本地私有数据」，公开版只放模拟题和模板。需要你决策
2. **⚠️ 政治内容体量比想象大**：四模块合计约 225 块，与 408 四门课总量相当。建议分批：马原先行（分值 24 分、最难、结构最像 408），验证效果后再批量铺开，避免一次性生成质量失控（quiz-ds-b 的 10 处答案错误就是教训）
3. **建议补一块「分析题背诵」**：政治 50 分分析题靠背诵，当前计划没覆盖。建议加一个 `recite` 块类型（正面问题/翻面答案要点/自评掌握度），放在各模块章末——这也是我之前提的自测模式的落地场景。可以作为政治第二批需求
4. **英语建议砍掉模拟题（至少推迟）**：模拟阅读质量参差，与真题思路有偏差，精读 44 篇真题已足够。建议第一批只做 2010-2015 六年 24 篇，跑通结构再决定
5. **时政的「考前汇总」依赖外部信息**：11 月对照押题卷补漏的动作需要你提供资料或授权我检索，方案里已注明
